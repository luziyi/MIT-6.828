## MIT-6.828

MIT 6.828课程，正式名称为  *Operating System Engineering* ，是麻省理工学院（MIT）开设的计算机科学与工程课程，主要讲解操作系统的设计与实现。课程内容侧重于操作系统的核心概念，如进程管理、内存管理、文件系统、硬件抽象等，同时通过实际的编程作业和项目帮助学生深入理解操作系统的工作原理。

### 课程目标

* **深入理解操作系统的基本概念** ：学习如何设计和实现一个操作系统的基本组件。
* **实践操作系统编程** ：通过编写和调试操作系统的实际代码，掌握内核级编程。
* **掌握并发和资源管理** ：学习操作系统如何处理多个进程的执行、内存分配和文件管理。
